Google Docs / RE2

Turn text into a search pattern.

Paste a sample. Letters, numbers, and spaces become flexible patterns. Wrap exact text in {...}.

Layout

Input

Ctrl+V paste · Enter newline

Enter newline · Ctrl+V paste. Letters, numbers and whitespace become flexible patterns. Wrap exact text in {...}, for example {Invoice} 123.

Output

Shift+Enter copies

Shift+Enter copy (output focused) · Ctrl+C copy selected text
Google Docs: Ctrl+H → Match using regular expressions.

Insert patterns

Drag into an editor or click to insert at the input cursor.

Quick type: :start:, :end: (Docs), or :para: (Word). Type {exact text} to keep text literal. Hover or focus a token for a hint.

Microsoft Word / Wildcards

Build a Word search pattern.

Paste sample text to generate Word wildcard search syntax. Letters become character patterns. Wrap exact text in {...}.

Layout

Input

Ctrl+V paste · Enter newline

Enter newline · Ctrl+V paste. Letters, numbers and whitespace become flexible patterns. Wrap exact text in {...}, for example {Invoice} 123.

Output

Word advanced Find

Shift+Enter copy (output focused) · Ctrl+C copy selected text
Word: Advanced Find → More → Use wildcards.

Insert patterns

Drag into an editor or click to insert at the input cursor.

Quick type: :start:, :end: (Docs), or :para: (Word). Type {exact text} to keep text literal. Hover or focus a token for a hint.

Reference / Searchable

Syntax guide.

Search by a character you pasted, a token like \d, or a description like “tab”, “digit”, or “non-breaking space”.

References: Google Docs Find and Replace · RE2 syntax · Word Find and Replace. Some operations are context-dependent; Word wildcards are not a one-to-one mapping to RE2.
