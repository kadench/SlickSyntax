Google Docs / RE2

Google Docs Regex Builder

Paste a sample. Letters, numbers, and spaces become flexible patterns. Wrap exact text in {...}.

Layout

Input

Ctrl+V paste · Enter newline

Enter newline · Ctrl+V paste. Letters, numbers and whitespace become flexible patterns. A ? means any one character; use {?} for a literal question mark. Wrap other exact text in {...}, for example {Invoice} 123.

Output

Shift+Enter saves

Shift+Enter save to history (and copy when output is focused) · Ctrl+C copy selected text
Google Docs: Ctrl+H → Match using regular expressions.

Insert patterns

Drag into an editor or click to insert at the input cursor.

Quick type: :start: , :end: (Docs), or :para: (Word). Type {exact text} to keep text literal. Hover or focus a token for a hint.

Reference / Searchable

Syntax guide.

Search by a character or decimal code point (for example, 33), a token like \d , or a description like “tab”, “digit”, or “non-breaking space”.

Type or paste characters, names, patterns, decimal values, or Unicode code points. Tab inserts a Tab; Shift+Tab moves focus.

References: Google Docs Find and Replace · RE2 syntax · Word Find and Replace · Python re . Some operations are context-dependent; Word wildcards are not a one-to-one mapping to RE2 or Python re.
